# TIRE CH 2

タイヤから、まだ知らない相棒へ。時間とお世話、寄り道の思い出で育つ、小さな車育成ゲーム。

[遊ぶ](https://wikeda.github.io/tire-ch/) · [v1のガレージ](https://wikeda.github.io/tire-ch/v1/)

## 新しい遊び
- 自然成長でタイヤ→足まわり→ハンドル→ボディ→相棒。完成まで約6分。留守中の成長は1回最大120秒、留守中に故障しません。
- お世話のタイミングと旅の選択を覚えます。磨きすぎや食べすぎも、思わぬ個性に。
- 名前も姿も、出会うまでひみつ。12種類の異なるシルエットを図鑑に集めます。
- 街・森・峠の短いおでかけ。熱や元気、パーツと引き換えに選ぶ小さな冒険。
- おやつは成長を加速しますが、熱が上がります。急ぎすぎた旅にも負担があります。
- 故障したら配線を順番につなぐ手作業か、パーツを使った強い回復。
- 気分転換に3タップのタイミング練習。ゆっくりモードあり。遊ばなくても育ちます。
- 星は旅の記録で、姿の良し悪しではありません。図鑑と記録は次の世代にも残ります。

## セーブ
このブラウザのlocalStorageに自動保存。端末間同期はありません。書き出し・読み込み対応。v1の元データは変更せず、旧図鑑を別に保管します。v1は旧ガレージでそのまま続けられます。v2プレビューと正式版は同じセーブを使います。

別タブとの競合時には保存を止め、最新セーブを読み込む案内を出します。対応ブラウザではWeb Locksで保存を直列化します。非対応ブラウザでは比較による競合検出のみなので、同時プレイは避けてください。

アカウント、課金、解析、バックエンドはありません。アートはオリジナルSVG。フォントはGoogle Fonts、読み込み失敗時はシステムフォントです。

## 開発と検証
Node.js22以降とPython3。`npm install`後、`npm test`、`node --test v2/tests/*.test.js`、`npm run test:e2e`。ブラウザテストはPlaywright ChromiumとPixel7エミュレーションです。

[独立プレイテスト記録](v2/docs/playtest-ledger.md) に、実際のUI操作、発見、修正、再確認を記載しています。単体テストや自動ブラウザ回帰は実プレイ回数に含めません。物理スマートフォンでの検証は行っていません。

v1原版は `v1-archive` ブランチと `v1/` に保存。新しいランタイムは `v2/`、ルートのHTMLも同じアセットを利用します。
