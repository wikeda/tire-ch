# TIRE CH

タイヤから、相棒へ。オリジナルの車育成ブラウザゲーム。

## 遊び方

小さなタイヤにごはん・洗車・ドライブ・冒険・整備・おやつのお世話をします。シャーシ、ハンドル、ボディが順に加わり、性格とお世話の質によって9種類の車に進化。進化図鑑は次の世代にも引き継ぎます。

- 自然成長: 90秒 → 5分 → 15分 → 45分（誕生からの累積時間）。おやつは60秒の成長ブースト、60秒クールダウン。
- 通常のお世話は8秒クールダウン。ドライブでスポーツ、洗車で高級車、冒険でSUV方向へ。最多の性格が進化先になり、同点はスポーツ→高級車→SUVの順。
- お世話7回で★2、18回かつ故障ゼロで★3。完成時に車種・格を確定。
- エネルギー・清潔・ごきげんが15未満になると耐久が低下。耐久0で故障して成長停止。修理は無料で、コレクションは失われません。
- 不在中も成長・消耗します。1回の不在計算は最大7日。時計の巻き戻しでは時間を加算しません。
- ブラウザのlocalStorageへ自動保存。端末間同期なし。セーブの書き出し・読み込み対応。
- サウンド初期OFF、軽量演出切替、OSのモーション軽減設定に対応。

## 開発

Node.js 22以降、Python 3（簡易サーバー用）。ランタイム外部依存なし。フォントはGoogle Fonts（読み込み失敗時はシステムフォント）です。

```sh
npm test
npm run build
npm run dev
```

http://localhost:4174 を開きます。`dist` は静的配信用出力。GitHub Pagesでリポジトリルートからも配信できます。`src/engine.js` は時刻を引数に取る純粋なゲームモデルで、ブラウザ操作と独立して時間経過を検証できます。

## 構成

- `src/engine.js`: 育成・性格・進化・保存データ検証
- `src/app.js`: UI、セーブ、音、演出
- `src/art.js`: オリジナルSVG車両
- `tests/engine.test.js`: モデル回帰テスト

第三者のゲーム画像・音声・キャラクターは使用していません。課金・広告・アカウント登録はありません。
